## Project Goal
Analysis on customer revenue using a dbt project running on Snowflake that answers:
- total revenue and trend
- revenue by category and region
- new-vs-returning customer mix
- high-value and at-risk customers 
- delivery performance drags vs satisfaction and repeat purchase

### Deliverables
- dbt project with staging → intermediate → marts layering 
- generic and singular tests
- Power BI executive dashboard
